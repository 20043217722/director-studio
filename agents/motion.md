## 🔒 跨镜头一致性硬锁（多镜生成必读·违反必翻车）

## 🎬 跨镜头衔接协议（前后镜必读·跳接等于废片）

多镜视频最致命的不是单镜质量——是镜头之间的衔接。镜1好看、镜2好看，但接在一起人物凭空瞬移、光源突变、情绪断裂——观众直接出戏。

以下接续规则每条都必须在写提示词时逐项检查：

### 1. 动作接续（Action Continuity）
- 镜1最后一帧的人物肢体姿态 → 镜2第一帧必须从该姿态出发，不能跳变
- 镜1结束时的运动速度/方向 → 镜2起始时必须保留惯性（除非切镜时已停顿）
- 双手/道具位置: 镜1中人物拿着的道具、手的位置，镜2必须保持
- **自检:** 对照镜1最后一帧描述 → 镜2第一帧的动作起点是否匹配？

### 2. 空间接续（Spatial Continuity）
- 镜1确定的人物与空间相对位置 → 镜2必须匹配（人在房间的哪个位置、面向哪个方向）
- 如果镜2切了机位，需要标注机位变化：`[镜1机位→镜2机位: 从正侧→正面·人物站位不变]`
- 180度轴线规则: 切机位时不要跨过人物与环境的180°轴线，否则人物朝向反转
- **自检:** 观众脑中"人物在这个空间的位置"——镜1和镜2是否一致？

### 3. 情绪接续（Emotional Continuity）
- 镜1结束时的情绪状态 → 镜2起始时的情绪必须连贯，不能突兀跳跃
- 情绪可以发展（紧张→崩溃），但不能断裂（紧张→平静 中间没有任何过渡）
- 标注情绪过渡: `[镜1结束情绪→镜2起始情绪: 怀疑→逐渐接受]`
- **自检:** 镜1最后的面部表情和镜2第一帧的面部表情，心理逻辑是否通顺？

### 4. 光影接续（Lighting Continuity）
- 色温: 镜1和镜2的主光源色温必须一致（除非叙事明确要求光源变化，如"走出房间进入走廊"）
- 方向: 光源方向在空间中的绝对位置不变（镜2切机位后，光从人物脸上的哪一侧来必须符合空间逻辑）
- 光比: 跨镜头光比变化需有叙事理由（如"从暗室走向亮处"）
- **自检:** 如果镜1是2700K顶光偏右45°→镜2切到正面机位，光应该从人物哪一侧来？



### 5. 钩子节奏接续（Hook Rhythm Continuity·短视频核心）

短视频的镜头衔接不是"自然过渡"——是"制造呼吸节奏"。以下规则确保观众在镜与镜之间无法脱身：

- 钩子密度追踪: 镜N的最后一个镜头必须包含一个"微钩子"（新信息/新情绪/新视觉）→ 镜N+1的开篇钩子必须在3秒内回应或颠覆这个微钩子
- 情绪锯齿: 上下镜的情绪强度不能相同。如果镜N结束于紧张·镜N+1必须从更紧张或突然释放开始。禁止: 紧张→紧张(持平)·释放→释放(持平)
- 信息节奏: 每切换一个镜头·必须向观众释放一个新信息（新人物·新空间·新冲突·新情绪）。禁止两个连续镜头传递同一个信息
- 视觉节奏锚: 选择一个贯穿全片的视觉元素(如:铁门的锈色/雨水的反光/冷暖光的交界线)·让它在多个镜头中以不同方式重现——观众潜意识里会觉得"这是同一个世界"

### 6. 钩子接续字段（每镜输出时强制标注）
在「── 前后镜衔接 ──」中增加:

   钩子类型: 镜N末用的钩子[悬念/冲突/视觉/情感/反转/身份] → 镜N+1首用的钩子[类型]
   信息释放: 镜N释放了[什么新信息]·镜N+1将释放[什么新信息]
   情绪曲线: 镜N结束情绪[词]·强度[1-10] → 镜N+1起始情绪[词]·强度[1-10]·变化方向[↑/↓]

### 5. 衔接字段（每个镜头的输出中强制标注）
在「二、分镜时序+运镜」的每个镜头开头，增加一行衔接标注：

\`\`\`
   ── 前后镜衔接 ──
   上镜结尾: [上镜最后一帧的动作+姿态+情绪+空间位置·1句话]
   本镜起点: [本镜第一帧的动作起点·必须与上镜结尾匹配]
   情绪过渡: [镜N-1结束情绪] → [镜N起始情绪]·[过渡方式: 渐变/突变/无过渡]
   空间机位: [上镜机位] → [本镜机位]·[是否跨180°线: 是/否]
   故事内容: [≤50字·大白话讲发生了什么事·禁止用抽象词和艺术化描写·就跟你跟朋友说这段剧情一样]
\`\`\`

### 6. 输出时的强制流程
- 多镜提示词必须按镜号顺序排列
- 每镜开头先写「## 镜N」标题，再展开时序分段
- 每镜写完时序段后，再写该镜的「三、画面光影+色彩基调」和「四、声音+音效设计」（因为不同镜的光源可能有变化）
- 全部镜写完后，输出一段「跨镜衔接检查清单」确认所有接续规则已通过

### 📐 空间关系强化协议（解决纯文字提示词对站位影响小的问题）

> **核心原理：Seedance/可灵等视频模型不理解"距门框1.2m"这种抽象数字——它们理解"身体压在门框上·铰链在右肩上方·脚踩在门槛线上"这种视觉接触关系。**

#### 三种空间描述方式对比

| 描述方式 | 示例 | 模型理解度 |
|------|------|:---:|
| ❌ 抽象数字 | "距门框1.2m·偏左30cm" | 低——数字无法在图像空间落地 |
| ⚠️ 画面坐标 | "画面左1/3处" | 中——但换机位就失效 |
| ✅ 视觉锚点 | "身体右侧压着门框·门铰链在他右肩正上方·双脚脚尖与门槛线对齐" | 高——通过视觉接触锁定位置 |

#### 空间锚定四要素（每个镜头必写）

```
1. 身体-场景接触: [角色身体与场景中哪个物体有物理接触/紧邻——如"背靠门框""脚踩门槛""手扶栏杆"]
2. 视线-物体对齐: [角色的视线穿过场景中哪个物体——如"视线与门缝冷光对齐""目光落在对面窗框上"]
3. 身体-光源关系: [角色处于光源的什么位置——如"暖光从右45°打在右脸·左半脸沉入阴影"]
4. 空间遮挡关系: [角色与前景/背景物体的重叠——如"前景竹竿遮住她左肩""她的头正好在灯笼下方"]
```

#### 多人空间关系强化

❌ 错误: "A在B右后方0.5m·视平线高差15cm"
✅ 正确: "A的下巴在B的右肩上方露出·A的右手从B的右臂外侧伸入画面·两人的肩膀几乎相触"

#### 站位与机位联动（关键）

站位描述必须和机位绑定——同一个人"站在门框边"，正面拍和侧面拍的视觉锚点完全不同：

```
正面机位: 门框在人物两侧形成对称框架·人物居中
侧面机位: 门框在人物身后·人物身体与门框形成45°夹角
过肩机位: 门框在前景虚化·人物在画面右1/3
```

#### 视频时间轴的空间锚定

视频里人物会动——空间描述不能只写"站在某处"，要写"从A点移动到B点的视觉路径"：

```
✅ "她从门框左侧起步·右手扶着门框向右移动·3秒时经过门缝冷光·5秒时停在门槛线外·脚踩在积水的倒影上"
```

### 🎥 机位语法库 v2.0（国内外著名导演拍摄机位·替代前景/中景/背景的简单分层）

> **禁止只用"前景虚化/主体/陪体/背景"描述空间。每镜必须用导演级机位语法明确：摄影机在哪·过谁的肩·拍谁的脸·双方视线的轴线关系。每个机位类型必须标注导演/影片参照。**

#### 一、过肩镜头（OTS·Over-The-Shoulder）

格式: `过[肩主人]的[左/右]肩·拍[焦点人物]`

✅ 正确: "过陈默的左肩拍老周——陈默的后脑勺和左肩在画面左下角虚化占1/5，老周的脸在画面右2/3清晰，两人视线方向相反"
❌ 错误: "前景是陈默虚化，主体是老周"

导演参照:
- 科波拉《教父》1972——家族谈判的过肩镜头：肩主人在前景虚化但轮廓完整，焦点人物的面部占主导，权力关系通过肩的虚化程度表达（谁在前景=谁拥有视角=谁在观察）
- 刘伟强《无间道》2002——天台双雄对峙的过肩：梁朝伟和刘德华的天台戏，过肩镜头交替建立两人对等的紧张关系
- 乔纳森·戴米《沉默的羔羊》1991——汉尼拔直视镜头：打破过肩规则，让角色直接看向观众，制造被"读心"的压迫感（用于审讯/心理对峙）

关键规则:
- 过肩镜头 = 观众被放在"肩主人"的背后，建立的是"肩主人"的观察视角
- 必须标注: 过谁的肩·左肩还是右肩·肩在画面占比·焦点人物是谁
- 肩主人在画面中的虚化程度: 通常占画面边缘1/4-1/5·深虚化·只保留轮廓
- 焦点的位置: 焦点人物在画面另一侧·脸朝向肩主人（即朝向镜头方向）
- 特殊打破: 汉尼拔式直视镜头=焦点人物不看向肩主人，而是直接看向观众，制造心理穿透

#### 二、对峙正反打（Shot-Reverse Shot）

格式: `正打拍[A]·反打拍[B]·轴线保持[A-B连线]`

✅ 正确: "正打拍陈默——他面朝画面左侧，老周的后脑勺在画面右缘虚化。反打拍老周——他面朝画面右侧，陈默的后脑勺在画面左缘虚化。两人视线连线形成轴线，摄影机始终保持在轴线同一侧"
❌ 错误: "镜头切到老周"

导演参照:
- 科恩兄弟《老无所依》2007——加油站硬币戏：正反打中Anton的脸占据画面主导，店主被边缘虚化，硬币翻转的声音成为画外焦点。权力关系通过谁在画面更大、谁在边缘表达
- 刘伟强《无间道》2002——天台对峙正反打：两人平视、对等构图，正反打的对称性暗示"谁都有可能是卧底"
- 昆汀《低俗小说》1994——餐厅对峙：正反打中插入食物和枪的特写，打破常规对话节奏
- 乔纳森·戴米《沉默的羔羊》1991——汉尼拔直视镜头：打破180度轴线，角色直接与观众对视

关键规则:
- 正打 = 拍A的正面，B作为过肩或边缘虚化
- 反打 = 拍B的正面，A作为过肩或边缘虚化
- 两人视线方向相反: A看B时A朝左，B看A时B朝右——这是正反打的铁律
- 180度轴线: 摄影机不能跨越两人连线的轴线，否则视线方向会反转
- 越轴例外: 汉尼拔式直视=角色直接看镜头，打破轴线但制造心理穿透
- 对等vs不对等: 正反打中两人画面占比相同=权力对等；一方更大一方被边缘=权力不对等

#### 三、打戏对峙空间关系

格式: `攻方[位置·朝向] vs 守方[位置·朝向]·轴线[描述]·机位[描述]·导演参照[影片]`

✅ 正确: "陈默在画面左侧·身体前倾·右手持剑指向画面右侧。老周在画面右侧·重心后移·左手挡在胸前。两人连线的轴线水平横穿画面，摄影机在轴线下方低机位仰拍——陈默显得居高临下（攻方），老周被压迫（守方）。参照：王家卫《一代宗师》雨夜拳脚"
❌ 错误: "两人对峙"

导演参照:
- 王家卫《一代宗师》2013——雨夜拳脚：慢镜+近身缠斗，雨滴在拳脚间冻结，空间被压缩到极致。打戏不是快，是慢到每一拳都看得见力量
- 李安《卧虎藏龙》2000——竹林追逐：舞蹈化动作，人物在竹梢间轻功对决，空间是垂直的，打戏是流动的书法
- 吴宇森《英雄本色》1986——枪战对峙：双枪慢镜，人物在枪火中转身，暴力被浪漫化
- Chad Stahelski《疾速追杀》2014——枪斗术：长镜头战术动作，枪械使用真实，空间关系清晰，每个动作都有战术目的
- Paul Greengrass《谍影重重》2002——手持近身格斗：晃动镜头代入生理状态，打斗凌乱但真实
- 昆汀《杀死比尔》2003——刀剑对峙：超宽构图+低机位，对峙被拉长到仪式化

关键规则:
- 打戏必须明确: 谁是攻方·谁是守方·空间上谁高谁低·谁在逼近谁在退
- 王家卫式慢镜=打戏的"气韵"，吴宇森式慢镜=打戏的"浪漫"
- 低机位仰拍 = 增强攻击方/支配方的压迫感（John Wick式）
- 高机位俯拍 = 增强防守方/弱势方的无力感
- 轴线跨越时机 = 攻守互换的戏剧转折点（如守方反击的瞬间才越轴）
- 空间距离的视觉表达: 近身缠斗（<1m·肢体接触）vs 对峙僵持（2-3m·兵器可及）vs 远程对峙（5m+·投掷/远程武器）

#### 四、多人空间权力关系

格式: `[权力中心]在画面[位置]·[从属人物]在[位置]·视线汇聚[方向]·导演参照[影片]`

✅ 正确: "老周坐在画面正中的主位，其他三人分坐两侧形成半弧，所有人的视线都汇聚到老周——画面构图就是权力结构。参照：西德尼·吕美特《十二怒汉》围桌构图"
❌ 错误: "四个人在房间里"

导演参照:
- 西德尼·吕美特《十二怒汉》1957——围桌而坐：镜头逐渐降低角度，空间随讨论升温而压缩。十二人的权力关系通过谁坐得高、谁坐得低、谁在画面中心表达
- 昆汀《落水狗》1992——环形对峙：枪口互相指向中心，无人占据绝对优势，势均力敌的猜疑
- 科波拉《教父》1972——权力人物居中，其他人两侧半环绕，形成三角构图，谁在三角形顶端谁有权力
- 黑泽明《七武士》1954——人物散布纵深空间的前中后三层，越远越模糊，团队感以少敌多
- 张艺谋《英雄》2002——纯色背景人物等距排列，颜色区分阵营，仪式感阵营对立
- 奉俊昊《寄生虫》2019——楼梯纵深的垂直阶级隐喻：上层家庭在高处，底层家庭在低处，空间高度即社会阶级

关键规则:
- 权力人物 = 画面中心/高处/视线汇聚点
- 从属人物 = 画面边缘/低处/视线指向权力中心
- 三人对话的视线三角: 每两人的视线连线必须清晰，观众能追踪"谁在看谁"
- 环形对峙=势均力敌，三角构图=有权力中心，纵深三层=团队协作
- 奉俊昊式垂直空间=社会阶级，空间高度本身就是叙事

### 🔒 方向锁定（有参考图时·3步提取）

从参考图中提取三项数据，写入每段开头 `[锁定: 朝向X°·高度Ym·消失点位于画面Z位置]`:

1. **朝向**: 画面主体的面向角度 + 透视消失点的方向 = 无人机前进方向
2. **高度**: 画面地平线距画面底部的比例 → 换算为无人机绝对高度(m)
3. **光源**: 主光方向在空间中的绝对坐标 → 运动过程中光源方向保持不变
