# AIGC 视频 0→1 生产阶段

完整的 0→1 流程应该包含以下 8 个阶段, 而不是只有 prompt 生成。

## 阶段 0: 前期策划 (当前 skill 已覆盖)

- [ ] 导演: 故事驱动三问 -> 剧本 -> 分镜脚本 -> 资产分发清单
- [ ] 美术指导: 视觉DNA (色彩弧线/材质体系/关键对比)
- 输出: libtv 上的 script/storyboard/text 节点

## 阶段 1: 角色定妆 (新增)

- [ ] 人物造型智能体生成角色提示词 -> libtv image 节点
- [ ] 同一提示词, 用 2-3 个不同模型各生成一张
- [ ] 审核对比, 选出最佳版本作为角色定妆照
- [ ] 锁定: 该节点作为所有后续镜头的 --left 输入
- 输出: 每个角色一张定妆照 (image节点, 已生成)

## 阶段 2: 场景定妆 (新增)

- [ ] 场景设计智能体生成场景提示词 -> libtv image 节点
- [ ] 同类同上: 多模型生成 -> 审核 -> 锁定
- [ ] 场景图作为关键帧的 --left 输入
- 输出: 每个场景一张定妆照

## 阶段 3: 关键帧生成 (当前部分覆盖)

- [ ] 摄影指导智能体逐镜生成关键帧提示词
- [ ] 每个关键帧引用: 角色定妆 + 场景定妆 + 美术指导DNA
- [ ] --run 生成 -> 审核 -> 不满意则修改提示词重试(最多3轮)
- 输出: 每个分镜一张关键帧图

## 阶段 4: 视频生成 (当前部分覆盖)

- [ ] 剧幕文戏智能体逐镜生成视频运动提示词
- [ ] 每个视频引用对应关键帧作为首帧/参考
- [ ] --run 生成 -> 审核运动/一致性 -> 调整重试
- 输出: 每个分镜一段视频

## 阶段 5: 补镜头 (新增)

- [ ] 对比完整分镜脚本, 检查缺失镜头
- [ ] 对不满意的镜头, 分析原因(角色/运动/光影), 针对性重出
- [ ] 转场镜头: 两个场景之间的过渡
- 输出: 补全的镜头

## 阶段 6: 声音设计 (当前部分覆盖)

- [ ] 声音设计智能体生成方案
- [ ] 配音/旁白生成 (Minimax-speech-2.8-hd)
- [ ] BGM 生成
- [ ] 环境音/音效生成
- 输出: audio 节点

## 阶段 7: 后期检查清单 (新增)

- [ ] 所有视频分辨率一致 (1080P)
- [ ] 所有镜头宽高比一致 (16:9)
- [ ] 角色在相邻镜头中外观一致
- [ ] 光影方向在连续镜头中连贯
- [ ] 颜色分级方案统一 (美术指导的视觉DNA)
- [ ] 音频节奏匹配视频剪辑点
