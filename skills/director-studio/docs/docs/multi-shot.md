# 多镜批量处理模式

## 自动分镜拆解

从导演输出的分镜脚本中, 按分镜N分隔符自动拆解为独立块。

## 批量创建命令

`ash
# 并行创建关键帧节点
for i in 1 2 3 4 5; do
  libtv node create "摄影指导-分镜" -t image     -s "model=Lib Image"     --prompt "<分镜关键帧提示词>" &
done
wait

# 依次创建视频节点
for i in 1 2 3 4 5; do
  libtv node create "视频-分镜" -t video     -s "model=Seedance 1.0 Pro"     --prompt "<分镜视频提示词>"     --left "摄影指导-分镜"
done
`

## 分组策略

`
画布布局:
 前期策划区         角色设计区          场景设计区
  剧本               人物造型-主角       场景-日景
  分镜脚本           人物造型-配角       场景-夜景
  视觉DNA                               场景-室内

 关键帧区           视频生成区          声音区
  摄影-分镜1~5       视频-分镜1~5        BGM
  摄影-分镜6~10      视频-分镜6~10       环境音
`

## 优先级标记

| 标记 | 含义 | 何时使用 |
|------|------|---------|
| [P0] | 必生成 | 剧本角色设定主场景 |
| [P1] | 应生成 | 关键帧主要视频 |
| [P2] | 可生成 | 配角过渡场景环境音 |
| [P3] | 可选 | 道具细节BGM字幕 |
