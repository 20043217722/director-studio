# 迭代优化工作流

## 常见问题解决方案

| 现象 | 原因 | 修复方式 |
|------|------|---------|
| 角色不同镜头长得不一样 | 面锚不一致 | 从第一张成功图提取面锚, 所有镜头逐字复用 |
| 场景光感不对 | 色彩HEX未锁定 | 取色器从参考图取色, 固定HEX |
| 视频运动不自然 | 运动描述模糊 | 增加"缓慢加速停顿"等节奏词+时间点 |
| 画面构图空 | 缺少前景背景层次 | 加"前景中景远景"三层描述 |
| 风格不像参考片 | 参考锚定太弱 | 写明"导演片名年份具体镜头" |

## 迭代流程

`
生成 -> 检查(用质量清单) -> 记录问题 -> 修改节点 -> --run重试
                                                  |
                                   最多3轮,仍不满意换模型
`

## libtv 迭代命令

`ash
# 查看节点当前状态
libtv node "人物造型-主角"

# 修改提示词
libtv node "人物造型-主角" --prompt "<优化后的新提示词>"

# 只改模型
libtv node "人物造型-主角" -s "model=Lib Image"

# 重新生成
libtv node "人物造型-主角" --run
`
