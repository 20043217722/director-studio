# 提示词质量检查清单

将提示词写入 libtv 节点之前逐项检查。全部通过再执行 --run。

## 硬性规则

- [ ] 分辨率已指定: image 含 --ar, video 含 ratio
- [ ] 模型名正确: 用 libtv model search 确认存在
- [ ] 无禁忌内容: 无暴力血腥色情政治敏感
- [ ] 视频提示词无静帧词: 摄影指导=静帧, 剧幕文戏=视频, 不可混用
- [ ] 人物造型含中英双语

## 质量规则

- [ ] 角色一致性锁: 同一角色多镜头使用完全相同面锚+HEX+服装
- [ ] 场景色彩一致: 同场景所有镜头使用相同色彩HEX
- [ ] 光影有方向: 主光源方向+色温(如"左上方45 暖黄3000K")
- [ ] 动作有速度: 视频运动含节奏词(缓慢快速突然逐渐)
- [ ] 景别有数值: 不用模糊词, 用标准景别
- [ ] 材质有触感: 不只说"木头的", 要说"旧橡木粗粝深棕磨损度3/5"

## 风格规则

- [ ] 风格锚点明确: 引用具体导演影片年份(如"岩井俊二情书1995")
- [ ] 色调方案完整: 主色+辅色+点缀色都有HEX
- [ ] 胶片感参数: 真人项目含颗粒度对比度饱和度数值

## 检查示例

坏: "一个女孩在雨夜中走路"
好: "年轻亚洲女性,25岁,苍白肤色,黑长直发,浅灰oversize卫衣,深蓝牛仔裤,撑透明伞,微微低头,社交恐惧的眼神躲闪,左眉尾有1.5cm断痕旧疤,岩井俊二情书1995美学,柔光去饱和青色褪色胶片调颗粒0.3,Canon C700 FF 35mm T1.5,冷蓝主调(#1a2a3a)+暖橙路灯点缀(#ff6b35),雨滴在伞面形成水幕 --ar 3:4"
