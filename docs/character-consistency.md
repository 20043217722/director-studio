# 角色一致性锁定工作流

AIGC 视频最大的翻车点: 同一角色在镜1和镜2里像两个不同的人。
下面这套工作流是经过验证的解法。

## 核心原理

**先出角色定妆照 -> 锁定 -> 所有后续镜头用 img2img 模式引用**

## 操作流程

### Step 1: 生成角色定妆照

```bash
# 人物造型智能体输出角色提示词后，创建角色图节点并立即生成
libtv node create "角色定妆-女主角" -t image -s "model=Lib Image"   --prompt "<人物造型智能体输出的完整提示词, 含面锚·HEX·服装·疤痕"

# 等待生成完成
libtv node "角色定妆-女主角" --run
```

### Step 2: 审核 + 多选

```bash
# 生成3-5个变体(改seed或用不同模型), 对比选出最佳
libtv node create "角色定妆-女主角-v2" -t image -s "model=Seedream 5.0 Pro"   --prompt "<同一条提示词>"
libtv node "角色定妆-女主角-v2" --run

libtv node create "角色定妆-女主角-v3" -t image -s "model=Seedream 5.0 Lite"   --prompt "<同一条提示词>"
libtv node "角色定妆-女主角-v3" --run
```

### Step 3: 锁定为参考图

选定最佳版本后, 该节点的生成结果作为所有后续镜头的 --left 输入:

```bash
# 场景图引用角色参考
libtv node create "场景-女主登场" -t image -s "model=Lib Image"   --prompt "<场景提示词, 含角色描述>"   --left "角色定妆-女主角"   # <- 角色参考锁定

# 关键帧引用角色参考
libtv node create "摄影指导-分镜1" -t image -s "model=Lib Image"   --prompt "<关键帧提示词>"   --left "角色定妆-女主角"   --left "场景-主场景"       # <- 可同时引用角色+场景

# 视频引用关键帧 (逐帧一致性)
libtv node create "视频-分镜1" -t video -s "model=Seedance 1.0 Pro"   --prompt "<视频运动提示词>"   --left "摄影指导-分镜1"
```

### Step 4: 跨模型一致性策略

| 方案 | 一致性 | 成本 | 适用 |
|------|--------|------|------|
| 同一模型 + 同一角色参考 | 最高 | 中 | 主要角色 |
| 同一模型 + 逐字面锚 | 高 | 低 | 配角 |
| 跨模型 + 逐字面锚 | 中 | 低 | 不推荐 |

## 面锚模板 (所有镜头必须逐字复用)

```
角色面锚: [姓名] | [性别] | [年龄]岁 | [面型] |
特征: 左眉尾1.5cm断痕旧疤·鼻梁右侧浅色雀斑3颗·右下唇微厚 |
发色: #1a1a1a·及肩·微卷·右侧耳后别到耳后 |
虹膜: #4a3728深褐·杏仁眼型·轻微内双 |
肤色: #f5e6d3·冷白调·T区轻微油光 |
服装: 浅灰oversize卫衣(#c4c4c4)·深蓝直筒牛仔裤(#1e3a5f) |
道具: 透明长柄雨伞·银色细框眼镜(#d4d4d4) |
```

⚠ 这条面锚必须在所有涉及该角色的节点提示词中 **100%逐字复制**, 不能改一个字。
